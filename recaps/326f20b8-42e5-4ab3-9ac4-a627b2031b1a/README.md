# 暑假新疆旅行穿搭建议

## 核心穿搭公式
夏装 + 长袖防晒衣 + 三合一冲锋衣。

## 不同场景建议
- **赛里木湖（阴天/傍晚）**：需备好冲锋衣，湖边长时间停留较冷。
- **赛里木湖（早晨看日出）**：气温较低，建议穿三合一冲锋衣，裤子建议叠穿（如防晒裤加丝袜）。
- **赛里木湖（晴天）**：以防晒为主，短袖/裙子均可，必须搭配长袖防晒衣和帽子。
- **自驾/路途**：车内温差大，随身携带一件外套备用。
- **草原活动**：裤装更方便，骑马需穿瑜伽裤或打底裤。
- **鞋子选择**：准备一双舒适的运动鞋（应对长距离徒步）及日常拍照用的老爹鞋或短靴。建议携带备用鞋，以防遇到下雨或泥泞草地弄脏鞋子。
