# 万域芳菲暑期滑冰课程通知

这是一份关于暑期滑冰课程的活动通知，旨在为计划参与的学员提供关键的课程日期、时间、地点及准备事项。

> 如何准备并顺利参与万域芳菲的暑期滑冰课程？

## 课程安排

本课程为期五天，集中安排在暑期。
- 课程日期为8月11日至8月15日，共计5天。
  > 8月11日-8月15日 连续5天
- 上课时间为每天下午13:00至15:00。
  > 每天下午 13:00-15:00
- 上课地点位于奥体一楼。
  > 奥体一楼

## 课程内容

课程涵盖了从零基础到进阶的滑冰技能及娱乐环节。
- 包含冰上安全知识与基础站姿教学。
  > 冰上安全与基础站姿
- 包含前进滑行与停止练习。
  > 前进滑行与停止练习
- 包含平衡控制训练与趣味冰上游戏。
  > 平衡控制与趣味冰上游戏

## 参与准备

请参与者遵循以下要求以确保课程顺利进行。
- 请提前15分钟到达场地。
  > 请提前15分钟到场
- 着装应便于运动，建议穿着长袖衣裤。
  > 穿着便于运动的长袖衣裤
- 需自备手套、长袜和饮用水。
  > 并自备手套、长袜和饮用水
