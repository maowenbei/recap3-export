# 埃及金字塔

### 概述
埃及金字塔是古埃及文明的象征，主要作为法老的陵墓，旨在保护其遗体并辅助其灵魂升往天界。其基座为正方形，侧面为三角形，结构宏伟，涉及巨大的物质与人力投入。

### 主要金字塔群
* **吉萨（Giza）**：拥有胡夫、卡夫拉和孟卡拉金字塔，是全球最著名的金字塔遗址，也是仅存的古代世界七大奇迹。
* **阿布西尔（Abusir）**：包含纽塞拉、内弗尔卡拉及萨胡拉等金字塔，多为阶梯式结构。
* **塞加拉（Saqqara）**：拥有埃及最古老的石造建筑——左塞尔阶梯金字塔。
* **达夏尔（Dahshur）**：包含著名的弯曲金字塔与红金字塔（世界最早的真金字塔）。
* **其他遗址**：包括阿布拉瓦须、美兹哥哈纳、利斯特、美杜姆、哈瓦拉及拉罕等。

### 建造之谜
目前尚无确切文献记载建造方法。学术界主要推测包括：
* **杠杆与坡道论**：利用人力、杠杆或环绕建筑的土制螺旋斜坡搬运石块。
* **滑移论**：在沙地上浇水减少摩擦力进行拖运。
* **混凝土浇筑论（存疑）**：推测上层部分为模具浇筑而成。

### 保护与版权
2007年，埃及当局提出法律草案，要求商业用途的复刻品需支付版权费，以资助古迹维护，但不限制艺术创作。
